# EbacStore - Landing Page com LESS

Projeto desenvolvido como exercício do curso EBAC, focado na aplicação profunda de LESS (pré-processador CSS) em uma landing page moderna e responsiva.

## Descrição

EbacStore é uma landing page de e-commerce fictício, com design premium, grid responsivo, animações suaves e uso intensivo de recursos do LESS: variáveis, mixins, nesting, maps, escaping, funções, operações matemáticas, imports e muito mais.

## Tecnologias

- **HTML5** semântico e acessível
- **LESS** (pré-processador CSS)
- **CSS3** (compilado a partir do LESS)
- **JavaScript** vanilla para interações (menu mobile)
- **Fontes**: Google Fonts (Inter)
- **Imagens**: Placeholder via picsum.photos
